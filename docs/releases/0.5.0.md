## RusTXT 0.5.0 — cross-platform Iced interface

RusTXT now uses Iced on Linux, Windows, and macOS. GTK is no longer required by the released editor.

- Restored the familiar tabs, menus, grouped Settings, and compact Find/Replace panel.
- Added readable, opaque tooltips explaining every Find/Replace button.
- Fixed menu and dialog darkening during hover redraws, including fractional display scaling.
- Preserved recovery snapshots, undo history, cursor and scroll positions, safe saves, and Arabic/English editing.

### Downloads

| Platform | Package |
|---|---|
| Linux x86_64 | `.tar.gz` (Ubuntu 22.04/glibc 2.35 or newer), Arch `.pkg.tar.zst`, Debian 13+ `.deb`, Fedora 42+ `.rpm` |
| Windows x86_64 | Extract the Windows ZIP and run `rustxt.exe` |
| macOS Apple Silicon | Extract the `arm64-macos.zip` and move RusTXT.app to Applications |
| macOS Intel | Extract the `x86_64-macos.zip` and move RusTXT.app to Applications |

macOS bundles are ad-hoc signed, not Apple-notarized. If macOS blocks the app, use System Settings → Privacy & Security → Open Anyway after reviewing the source of the download. Windows executables are unsigned; the portable ZIP includes the C runtime.

Close the previous GTK version before starting 0.5.0: both use the same recovery database. Existing notes and settings are retained. macOS uses in-window menus; printing uses the default browser's print dialog.

Native unit and renderer regression tests run on Linux, Windows, Apple Silicon macOS, and Intel macOS. Native startup checks cover Unicode filenames, single-instance forwarding, and recovery. Linux additionally runs real-window editing/recovery and hover-rendering end-to-end tests, plus clean installation tests for Arch, Debian, and Fedora packages. Verify downloads against `SHA256SUMS`.
